# Plataforma de Juegos Educativos Interactivos (Word Connect)

Este proyecto es una plataforma interactiva construida con arquitectura modular basada en **Docker Compose**[cite: 1, 2].

## 🛠️ Tecnologías y Lenguajes Utizados
* **Frontend:** Ionic Framework + Angular (Canvas HTML5 para el videojuego de conectar letras)[cite: 1, 2].
* **Backend:** Node.js con Express API Rest.
* **Base de Datos:** MariaDB 10.11.
* **Contenedores:** Docker & Docker Compose[cite: 1, 2].
